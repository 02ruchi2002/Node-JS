

middlewear is the function in express js that runs before the final route handler

In Node.js (especially Express.js), middleware is a function that runs between the request (client) and the response (server).
It can modify the request, response, or run some logic before the final route handler executes.



-------- benifites ------------------

1. modifies Request
2. centerlized logic
3. auth
4. third party support
5.  static file handling
6. 404 page handling



------- types of middlewear---------------

1. application level     app.user() / app.get()
2. router level          router.use()
3 .bultin middleware
4. error handling        (err,req,res,next)
5. third party



______________________________________________     ⭐ Why Middleware?

Middleware is used for things like:

1. Logging

2. Authentication / Authorization

3. Parsing request body

4. Error handling

5. Validating input

6. Serving static files

7. Rate limiting

8. Handling sessions/cookies


 _____________________________________________________ ⭐  Types of Middleware in Express.js

1️⃣ Application-level Middleware

Applied to the entire app.

app.use((req, res, next) => {
  console.log("Time:", Date.now());
  next();
});


2️⃣ Router-level Middleware

Used only on a specific router.

const express = require('express');
const router = express.Router();

router.use((req, res, next) => {
  console.log("Router middleware");
  next();
});

router.get('/user', (req, res) => {
  res.send("User Page");
});

app.use(router);


3️⃣ Built-in Middleware (Express)

Examples:

express.json() → Parse JSON body

express.urlencoded() → Parse form data

express.static() → Serve static files


app.use(express.json());
app.use(express.urlencoded({extented:true}))


4️⃣ Third-party Middleware

Installed using npm.

Examples:

cors

morgan (logger)

cookie-parser

helmet

multer (file uploads)

const morgan = require('morgan');
app.use(morgan('dev'));


5️⃣ Error-handling Middleware

Has 4 parameters: (err, req, res, next)

app.use((err, req, res, next) => {
  console.error(err.stack);
  res.status(500).send("Something broke!");
});

___________________________________________ ⭐ Flow of Middleware

Client → Middleware 1 → Middleware 2 → Route Handler → Response
